# Round 2 extraction: everything still playing Pikachu's own animation.
#
# SSBU names an animation identically on every fighter, so each filename below was read out of
# PIKACHU's motion_list (tools/motion-patch/target/release/animof.exe) and then requested from the
# SOURCE fighter's directory. That is the same property that makes the drop-in a plain file
# replacement (ADR 0003), verified 11/11 on the first batch.
#
# Playtest gaps this closes:
#   - "krool dair transitions straight to the animation of base pikachu landing dair, same with
#      fair, bair, uair" -> the five landing_air_* animations
#   - "certain moves, like dtilt and dsmash, still have base pikachu animations"
#   - smash charge holds, which are a separate motion from the swing
#   - the angled f-tilt variants, which share Mythra's s3 script but not her animation
